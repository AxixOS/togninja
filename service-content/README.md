## How to apply with VS Code Agent (recommended)
For each page:
1) Open the file/component/template that renders that service page.
2) Locate the current content block (main section).
3) Replace it with the corresponding Markdown file from this pack.

### Copy-paste prompt template
Use this (edit the page name + file):
- Open the service page file for: <SERVICE PAGE NAME>
- Replace the main content with the full contents of: /mnt/data/new_age_service_pages/<MARKDOWN FILE>
- Keep existing header/footer/navigation unchanged.
- Ensure internal link to <a href="/warteliste/">Warteliste</a> remains intact.
- Ensure there is exactly one external link (already present).
